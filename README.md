# Plant-Tissue-Culture-Medianator
[Compare Plant Tissue Culture Media Formulations](https://heaslon.github.io/Plant-Tissue-Culture-Medianator/MediaComparinatorJuly2026.html). Design your own. Print your recipes and Stock Sheets. Salts and vitamins only. You are on your own for the rest.

Use it directly in your browser or download the HTML file to run locally offline.
